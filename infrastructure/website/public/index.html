01 / Cały projekt

Więcej niż przycisk „optymalizuj”.

Interfejs pokazuje plan. Host prowadzi sesję. Usługi mają własny zakres i zabezpieczenia.

01WinUI 3 · bez podwyższenia

Biblioteka gier i Tryb gry

Lokalna biblioteka ze Steam, Epic, GOG, Roblox i dostępnych instalacji Xbox. Plan sesji, reguły dla każdej gry, historia i diagnostyka w natywnym interfejsie.

UI działa z uprawnieniami użytkownika; operacje uprzywilejowane przekazuje do hosta.

02Backend · UAC

SessionHost

Klasyfikuje procesy i prowadzi transakcyjną sesję w czterech fazach. Obsługuje reguły tła, priorytety i affinity, czyli przydział rdzeni procesora.

PresentMon 2.5.1 zbiera rzeczywiste zdarzenia ETW dla procesów gry — to źródło FPS i czasu klatki.

03LocalSystem

System Optimizer

Osobny interfejs i usługa DismodeSystemAgent. Usługa sprawdza zaufanych sygnatariuszy klientów, prowadzi dziennik maszyny i nadzoruje recovery niezależnie od okna.

Wykonywalne są tylko pozycje ze zweryfikowanym adapterem. Bez zaufanego podpisu: tylko odczyt.

04Opcjonalny · GPL-3.0-only

Dismode Memory Optimizer

Niezależny składnik z własnym zasobnikiem i usługą LocalSystem. Pozostaje aktywny po zamknięciu części gamingowej; można go odznaczyć w instalatorze.

Operacje pamięci przechodzą przez ochronę sesji gry. Czyszczenie pamięci nie jest obietnicą dodatkowych FPS.

05FPS / frametime

Nakładka pomiarowa

Natywne okno topmost: pozostaje nad grą, przepuszcza wejście i nie przejmuje fokusu. Ustawiasz krycie, skalę i róg ekranu; możesz ją wyłączyć.

Gdy źródło nie dostarcza aktualnych danych, pomiar jest niedostępny. Program nie zastępuje go szacunkiem.

06Automat w zasobniku

„Optymalizuj w locie”

Wykrywa grę uruchomioną poza Dismode i podpina sesję z zapisanymi regułami. Działa także z zasobnika. Reguła dla konkretnej gry ma pierwszeństwo przed globalną.

Automat nie uruchamia gry. Po ręcznym zakończeniu sesji czeka na jej kolejne uruchomienie.

07Dziennik recovery

Przywracanie po awarii

Niedokończona sesja zostawia ślad w dzienniku. Tryb przywracania korzysta z zapisanych stanów, aby cofnąć priorytety i affinity oraz przywrócić wybrane aplikacje tła.

Recovery nie nadpisuje ślepo zmian dokonanych przez inne programy.

08Tylko offline / single-player

Menedżer OptiScaler

Osobna funkcja dla wybranej gry: weryfikacja SHA-256 pobranego wydania, kopia podmienianych plików i przywrócenie przy usuwaniu.

Instaluje proxy DLL. Wymaga potwierdzenia gry offline lub single-player; blokuje wykryty anti-cheat, gry tylko online i działającą grę.

02 / Jak działa sesja

Nic, czego nie da się cofnąć.

Każda zmiana przechodzi walidację, zapis intencji i stanu oryginalnego, wykonanie oraz weryfikację wyniku.

  1. 01

    Plan

    Wybierasz reguły dla gry i aplikacji tła. Procesy Windows, launchery, komponenty anti-cheat i pomocnicy gry są chronieni przed optymalizacją tła.

  2. 02

    Dziennik

    Przed zmianą zapisywany jest stan potrzebny do cofnięcia operacji. Dziennik recovery jest dopisywany i działa niezależnie od bazy SQLite.

  3. 03

    Sesja gry

    Host stosuje plan, śledzi grę i jej procesy potomne oraz zbiera FPS i frametime przez PresentMon. Uruchamiana gra zachowuje zwykłe uprawnienia użytkownika.

  4. 04

    Przywrócenie

    Po grze operacje są cofane w odwrotnej kolejności: wracają priorytety, affinity i wybrane aplikacje tła. Stan jest sprawdzany z uwzględnieniem zmian zewnętrznych.

↶

A jeśli SessionHost ulegnie awarii?

Przywracanie opiera się na dzienniku niedokończonej sesji, a nadzór usługi nie kończy się wraz z zamknięciem UI. Przy kolejnym uruchomieniu recovery pozwala dokończyć cofanie zapisanych zmian. Najpierw zakończ przywracanie, potem aktualizuj program.

03 / Bezpieczeństwo i prywatność

Uprawnienia mają granice.
Dane zostają u Ciebie.

  • Bez sterownika kernel-mode.Natywne API Windows; bez Electron i WebView.
  • Interfejs bez uprawnień administratora.UAC dotyczy SessionHost. UI nie wykonuje bezpośrednio uprzywilejowanych operacji.
  • Podpisy i zaufani wydawcy.Łańcuch wydania produkcyjnego wymaga Authenticode. Usługa porównuje podpis klienta z zainstalowaną listą zaufanych wydawców.
  • Zabezpieczenia pozostają chronione.Zmiany zabezpieczeń systemu i anti-cheat są zablokowane. Reguły użytkownika nie omijają polityki bezpieczeństwa.

Dane i połączenia

Bez kont, chmury i telemetrii produktu.

Profile, ścieżki EXE, skróty hashy, ustawienia, listy procesów i usług, historia, dzienniki oraz wyniki FPS/frametime są zapisywane lokalnie.

Dane użytkownika
%LocalAppData%\Dismode
Dane maszyny i recovery
%ProgramData%\Dismode

Sprawdzanie aktualizacji łączy się przez HTTPS z serwerem Dismode. Operator może otrzymać IP, czas żądania, wersję protokołu i User-Agent z nazwą oraz wersją programu. Listy gier, procesów, usług, sprzętu i wyników nie są przesyłane.

Automatyczne sprawdzanie (domyślnie co 30 dni) i automatyczną instalację wyłączysz niezależnie w zakładce Aktualizacje. Usunięcie danych przy pełnej deinstalacji wymaga zakończonego recovery.

06 / FAQ

Zanim włączysz optymalizację.

Czy Dismode jest bezpieczny dla anti-cheat?

Tryb gry nie wstrzykuje kodu do gry i nie ma sterownika kernel-mode. Zmienia priorytety, affinity i działanie wybranych aplikacji tła; komponenty anti-cheat są wyłączone z optymalizacji tła. To nie jest gwarancja zgodności z konkretnym anti-cheatem — sprawdź zasady danej gry.

Osobny menedżer OptiScaler instaluje proxy DLL. Wymaga potwierdzenia offline lub single-player i blokuje instalację przy wykrytym anti-cheacie oraz dla gier tylko online.

Co się stanie po awarii hosta lub zamknięciu okna?

Zamknięcie UI nie wyłącza nadzoru usługi nad recovery. Po awarii hosta dziennik pozwala wznowić przywracanie zapisanych priorytetów, affinity i aplikacji tła. Nie aktualizuj ani nie usuwaj danych przed zakończeniem recovery.

Czy dostanę więcej FPS?

Nie ma gwarantowanego przyrostu. PresentMon 2.5.1 mierzy FPS i czas klatki na podstawie rzeczywistych zdarzeń ETW dla śledzonej gry. Brak lub nieaktualne dane są pokazywane jako niedostępne. Memory Optimizer nie jest funkcją zwiększania FPS.

Dlaczego program prosi o uprawnienia administratora?

SessionHost potrzebuje UAC do wykonywania planu sesji. Interfejs WinUI 3 pozostaje niepodwyższony, a uruchamiane gry i przywracane aplikacje korzystają ze zwykłego tokenu użytkownika. Osobna usługa systemowa działa jako LocalSystem.

Czy muszę instalować Memory Optimizer?

Nie. Jest domyślnie zaznaczonym, niezależnym składnikiem GPL-3.0-only, który możesz odznaczyć w instalatorze. Ma własny zasobnik i usługę; zamknięcie gamingowego Dismode go nie wyłącza.

Czy program działa offline i wysyła moje dane?

Sesje i dane są lokalne, bez kont, chmury i telemetrii produktu. Sprawdzanie aktualizacji wymaga HTTPS; serwer może widzieć standardowe metadane połączenia, ale nie otrzymuje list gier, procesów ani wyników pomiarów. Pobieranie wydań OptiScaler również wymaga sieci.

Mam GameShift. Czy stracę bibliotekę i profile?

Dismode to ten sam program pod nową nazwą. Instalator przenosi dane. Jeśli GameShift nadal działa albo pliki są w użyciu, Dismode wstrzymuje start i wyświetla wyjaśnienie. Zamknij starą wersję oraz programy blokujące pliki i ponów uruchomienie.

Czy działa na Windows 10, ARM lub laptopie?

Wymagania to Windows 11 x64, wersja 23H2 lub nowsza. Docelowym sprzętem są komputery stacjonarne. Profile baterii laptopów nie należą do obecnego zakresu projektu.
